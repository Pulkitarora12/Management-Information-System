New Custom Form

Example: Form Name = "Shift Inspection", Form Key = shift_inspection (lowercase, underscores only - used internally, never shown to users).

Fields

How to add fields: click "+ Add Field" for each piece of data this form should collect. Field Key is the internal name (lowercase, underscores, e.g. machine_number); Label is what the user sees (e.g. "Machine Number"). Pick the Type that matches what will be entered:
TEXTany short text, e.g. "Line A"
NUMBERwhole numbers, e.g. 42
DECIMALnumbers with decimals, e.g. 12.5
DATEa calendar date
BOOLEANYes/No
DROPDOWNone choice from a fixed list (entered as free text for now)
MASTER_REFa reference to another master record (entered as free text for now)
FILEa filename/path (no real upload yet)
